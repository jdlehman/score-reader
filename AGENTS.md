# Notes for coding agents

- **Music in this repository.** It is public, so no page, scan, photo, PDF, MusicXML or answer
  file is committed until its licence is checked against "What may be committed" in
  `test/corpus/README.md`, and recorded there (or in its folder's README). That covers pull
  requests too: a PR that adds music names each file's source and licence. Read the licence on
  the file itself, not only the site's listing.
- A private copy of a score (a choir's own, one someone shared) goes nowhere: not in git, not in
  the test set. Read it from where it is.
- `NOTES.md` explains each change to Audiveris.
- **A change to how pages are read goes in only when `test/prove.mjs` proves it better**
  (`test/corpus/README.md`, "Proving a change", has the rule). That covers pull requests: one that
  changes reading includes the verdict it got. One that claims to change nothing needs no verdict,
  but has to do something else useful.
